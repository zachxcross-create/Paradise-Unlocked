PARADISE UNLOCKED
=================

Happy Home Paradise furniture unlocker for Animal Crossing: New Horizons.

BEFORE YOU BEGIN
- Happy Home Paradise DLC must be installed, and Paradise Planning accessible.
- You need an existing save and an emulator that provides access to its save files.
- Use Chrome or Edge on your computer.
- Tested with ACNH 3.0.3; other versions are untested.

HOW TO USE
1. Close the game. Back up your entire Animal Crossing save.
2. In your emulator, right-click Animal Crossing: New Horizons and open its user save directory.
3. Locate the folder named 0. Compress the ENTIRE 0 folder into a ZIP file.
   The ZIP should contain 0/main.dat, 0/Villager0/, and other save files.
4. Extract ALL files from this Paradise Unlocked download into the same folder.
5. Double-click Launch Save Editor.html to open Paradise Unlocked in Chrome or Edge.
6. Choose your save ZIP, then click Unlock furniture.
7. Extract the downloaded modified ZIP and restore its 0 folder to your emulator's save location.
   Keep your original backup in case you want to revert.

IMPORTANT
- The utility runs locally in your browser; your save is not sent to a server.
- DIY recipes are not separately unlocked. See the optional NHSE instructions in the app.
- Do not run the tool on the only copy of your save.

OPTIONAL: DIY FURNITURE IN HAPPY HOME PARADISE
Want DIY furniture available in HHP without learning the recipes on your main island?
Use NHSE (New Horizons Save Editor):
https://github.com/kwsch/NHSE/releases

1. Back up your save and open the extracted main.dat file in NHSE.
2. Go to Edit Player > Edit Recipes.
3. Click Craft All (do not choose Learn All).
4. Click Save in the recipe editor.
5. Return to the main NHSE window and choose File > Save.
6. Restore the edited save and launch the game.

Note: After Craft All, NHSE may still show some recipes as not crafted.
The crafted flags can nevertheless take effect in-game.
