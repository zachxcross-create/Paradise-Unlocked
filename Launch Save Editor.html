Paradise Unlocked

Happy Home Paradise furniture catalog unlocker for Animal Crossing: New Horizons.

Requirements

  • Animal Crossing: New Horizons with the Happy Home Paradise DLC installed.
  • An existing save with Paradise Planning accessible.
  • Ryujinx or another compatible emulator, and Chrome or Edge.

Prepare your save

Back up your entire save. Close the game, then locate your Animal Crossing save directory. In your emulator, right-click Animal Crossing and select Open User Save Directory (or the equivalent option).

Locate the folder named 0 and compress that entire folder into a ZIP file. ✓ Correct ZIP structure

YourSave.zip
└── 0/
    ├── main.dat
    ├── mainHeader.dat
    ├── landname.dat
    ├── Photograph/
    └── Villager0/
        ├── personal.dat
        ├── personalHeader.dat
        └── ...

This tool processes your save file locally in your browser, without sending your data to a server. It unlocks all villager-associated HHP furniture in your existing save.

Once the modified ZIP downloads, extract it and restore the 0 folder to your emulator's save location. Keep your original backup.

Optional: Unlock DIY Furniture

Want DIY furniture available in Happy Home Paradise without unlocking the recipes on your main island? Use NHSE (New Horizons Save Editor) to mark recipes as crafted without marking them as learned.

  1. Download and open NHSE.
  2. Open main.dat from your extracted save folder.
  3. Select Edit Player → Edit Recipes.
  4. Click Craft All. NHSE may not visually mark every recipe as crafted after selecting Craft All. The changes can still take effect when you load your game.
  5. Click Save in the recipe editor.
  6. Return to NHSE's main window.
  7. Select File → Save to save your changes.

Keep a backup before editing your save.
